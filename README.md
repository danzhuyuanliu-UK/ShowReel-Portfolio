# Zhuyuan Liu — Selected Work

这是可直接部署至 GitHub Pages 的静态网站，无需安装依赖或构建。

## 上传
1. 解压 ZIP，将所有文件和 assets 文件夹上传到 GitHub 仓库根目录；不要直接上传 ZIP，也不要额外套一层文件夹。
2. 仓库 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 / (root)，然后保存。
3. GitHub 完成发布后，在 Pages 页面打开生成的网址。

## 内容与修改
- index.html：文字、视频和 Technical Research 链接。
- style.css：字体、颜色、排版和手机布局。
- script.js：点击封面后加载视频。
- portfolio.pdf：最新16页作品集，含首页 Showreel 和尾页研究链接。
- cv.pdf：CV。
- assets/：网站图像；请保持文件夹和相对路径不变。
- .nojekyll：保留此文件，禁用不需要的 Jekyll 处理。

无需域名、付费服务、ChatGPT 登录或后端。视频需要联网，并受 Vimeo / YouTube 自身的播放与嵌入权限控制。Technical Research 使用原 Google Drive 分享链接，保留其现有访问权限。

本包仅在本地生成，没有更新 ChatGPT 托管网站，也没有上传到 GitHub。
